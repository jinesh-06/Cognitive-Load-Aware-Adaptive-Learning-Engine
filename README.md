# Cognitive Load Aware Adaptive Learning Engine

An AI-powered adaptive learning platform that analyzes learner behavior and cognitive load to provide personalized learning experiences.

## Tech Stack

- Python
- React
- JavaScript
- Machine Learning
- RAG
- Vite

## Features

- Cognitive load prediction
- Adaptive learning
- Personalized content
- Quiz and learning analytics
- AI-based concept explanation
- RAG-based knowledge retrieval
